# unified-desktop (working codename)

Connect an Android phone to any PC, by cable or Wi-Fi, and the PC becomes a locked,
full-screen desktop that runs Windows, Linux and Android apps, all running on the phone. The
phone stays usable the whole time. One Exit button gives the PC back.

**No product name yet.** The owner chooses one later. Never invent one.
